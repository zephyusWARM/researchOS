# PROGRAM

## Core question

Given the exact Taiwan MJ longitudinal health-examination cohort structure used for incident ultrasound-confirmed NAFLD, what scientifically meaningful questions remain genuinely unresolved, and which can this dataset answer unusually well?

## Dataset facts supplied by the user and awaiting source-level verification

- Taiwan MJ longitudinal health examination cohort, 1996–2016
- 62,660 participants; 160,650 longitudinal follow-up interval records
- 219 fields; 18,959 incident NAFLD cases
- repeated demographic, clinical, laboratory, lifestyle measurements
- residential PM2.5, NO2, CO exposure
- time-varying variables, censoring, incident NAFLD by abdominal ultrasonography
- course target variable: NAFLD2_1()

## Research rules

1. Reverse-engineer information content before considering models.
2. Search 2015–2026, with deeper coverage of 2020–2026.
3. Cover NAFLD/MASLD prediction, dynamic survival prediction, biomarker trajectories, environmental-metabolic questions, and causal/interpretive limits.
4. Extract what each close paper has already answered, not merely its model.
5. Build a question × data-structure saturation map; any green region must survive at least three reverse-search query families.
6. Generate candidate problems only after the landscape is mapped.
7. Red-team interval censoring, irregular visits, informative visiting/censoring, temporal leakage, residential exposure error, mobility, missingness, historical dataset shift, MASLD-definition mismatch, and clinical utility.
8. Identify irreducible simple baselines before complex methods.
9. Final ranking criterion: scientific importance, genuine novelty, dataset fit, validity, master-level feasibility, and runway to serious research.
10. If a question becomes uninteresting without deep learning, treat it as method-first and downgrade it.
