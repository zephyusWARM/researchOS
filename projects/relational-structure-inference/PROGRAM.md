# Program — Relational Structure Inference

## Mission

Build a durable, source-backed map of the research lineage around **Neural Relational Inference (NRI, 2018)** and the broader problem of inferring latent interaction structure from observations or dynamics.

The program is not a recency list. It should determine which works are actually structurally important, which are direct descendants of NRI, which belong to adjacent traditions, and what a rigorous reading path should be for learning relational inductive bias, structured representation, graph discovery, and scientific machine learning.

## Core questions

- What are NRI's nearest conceptual ancestors?
- Which later methods are genuine descendants versus merely adjacent graph-structure-learning work?
- When does accurate dynamics prediction imply, fail to imply, or conflict with correct structure recovery?
- What assumptions are doing the real work: pairwise interactions, discrete relation types, stationarity, observability, sampling rate, identifiable latent variables?
- How do dynamic graphs, continuous-time systems, causal discovery, object-centric models, equivariant physics models, and higher-order/hypergraph methods connect or diverge?
- Which papers change the conceptual map enough to deserve priority in a serious curriculum?

## Source policy

Prefer primary papers, official proceedings/journals, author repositories, and authoritative technical artifacts. Citation counts or recent publication dates may inform discovery but do not determine importance.

## Persistence policy

GitHub is a durable state layer, not a live notebook. Research in batches. Persist only after a meaningful epistemic delta, recovery-critical checkpoint, or coherent milestone. Do not create one commit per paper or query.
